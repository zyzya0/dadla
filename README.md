# Doodle Jump (Java, Android)

Простая копия Doodle Jump: человечек сам прыгает по платформам, а вы управляете
им наклоном телефона или пальцем. Весь код — на Java, без сторонних библиотек.

**Готовый APK:** `Download/DoodleJump.apk` (в папке проекта тоже лежит копия).

## Как играть

- Тапните по экрану, чтобы начать.
- **Наклон телефона** влево/вправо — движение (акселерометр).
- **Палец на экране** — человечек следует за пальцем (работает и без датчика).
- Края экрана «сквозные»: ушёл за правый край — появился слева.
- Упал вниз — конец игры, тапните, чтобы начать заново.
- Рекорд запоминается в настройках приложения.

## Что внутри

| Файл | Назначение |
|------|------------|
| `AndroidManifest.xml` | манифест (minSdk 21, targetSdk 34, портрет, без заголовка) |
| `src/com/narezany/doodlejump/MainActivity.java` | активити, полноэкранный режим |
| `src/com/narezany/doodlejump/GameView.java` | вся игра: физика, отрисовка, сенсор |
| `res/values/strings.xml` | название приложения |
| `res/mipmap-xxhdpi/ic_launcher.png` | иконка |
| `tools/apkpack.py` | упаковка APK с выравниванием `classes.dex` / `resources.arsc` |
| `build.sh` | сборка APK |
| `doodle.jks` | ключ подписи (пароль `doodlejump`, alias `doodle`) |

## Физика (в dp, чтобы одинаково на любом экране)

- гравитация 2500 dp/с², импульс прыжка 1150 dp/с → высота прыжка ≈ 265 dp;
- расстояние между платформами 80–145 dp (растёт до 168 dp со счётом);
- максимальная скорость падения 1800 dp/с, по горизонтали 950 dp/с;
- камера держит человечка на 38 % высоты экрана, счёт = пройденные dp / 12;
- платформы переиспользуются: ушедшие вниз переезжают наверх.

## Пересборка

Нужны: JDK, `android.jar` (platform 35), `aapt2` для aarch64, `d8`, `apksigner`
(всё качается из репозитория Termux, в Alpine самого aapt нет).

```sh
sh build.sh            # результат: /tmp/djbuild/DoodleJump.apk
```

`build.sh` ожидает инструменты в `/tmp/tx` и `/tmp/plat/android-35/android.jar`
(подробности — в шапке скрипта). Ключ создаётся один раз и подписывает
последующие версии, чтобы обновления ставились поверх.
